# Barfi King

Gujarati-first website for Jalaram Sweets & Namkeen, made by Barfi King. English is the second language. More languages can be added later in `src/features/i18n/copy.ts`.

## Run

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Pages

- `/` home
- `/shop` full price list, with category filters
- `/product/[slug]` one item, with a phone and WhatsApp order
- `/contact` shop and maker numbers

Prices come from the shop’s own menu cards. Farsan prices were not printed, so those items ask the customer to call. Ordering is by phone or WhatsApp. There is no online payment yet.
